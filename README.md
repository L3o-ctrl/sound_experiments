## Current projects:

* create 2 sine waves, one of which has an adjustable phase both with adjustable frequency
* create a tuner. Code that tells the dominant frequency

### single sine wave project:(not as complete as the tuner)
run `single wave.py` and use A/D keys to change the
phase up to 2*pi. Use Arrows R/L to change the 
frequency.

### tuner project:
run `mic_fft.py` in a terminal and play a note outside the computer
(works well with a piano) and see the note and frequency (eg. 440 A 4)
